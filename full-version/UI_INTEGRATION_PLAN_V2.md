# خطة دمج وتطوير واجهات منصة معاذ عليان

تهدف هذه الخطة إلى تفصيل هيكلة لوحة التحكم والصفحات الأمامية (Frontend) وربطها بشكل كامل، مع تحديد حقول الإدخال والعمليات (CRUD) لكل قسم.

## 1. الصفحات الأمامية (Frontend)

*   **الصفحة الرئيسية (Home):**
    *   **الأقسام الديناميكية:** Hero Section (القسم الرئيسي)، إحصائيات، قسم الكتب (Slider)، قسم الفيديوهات/البث المباشر، وقسم المقولات.
*   **صفحة الدورات (Courses):** عرض الدورات المتاحة مع تصفية وبحث.
*   **صفحة تفاصيل الدورة (Course Details):** عرض محتوى الدورة، المنهج، والأسعار.
*   **صفحة المقالات/المدونة (Articles):** عرض المقالات والأخبار.
*   **صفحة تفاصيل المقال (Article Details):** قراءة المقال.

---

## 2. لوحة تحكم الإدارة (Dashboard CRUDs)

### أ. إدارة الصفحات الثابتة (الأقسام) - Frontend Sections Management
هذا هو الجزء الخاص بالتحكم في الصفحات الثابتة ومحتوى كل سيكشن. سنعتمد على نموذج "إعدادات الأقسام" (Section Settings) أو (Pages).
*   **نوع العمليات:** تعديل (Edit) فقط لأن الأقسام ثابتة.
*   **الأقسام القابلة للتعديل:**
    1.  **القسم الرئيسي (Hero):**
        *   **المدخلات (Inputs):** العنوان الرئيسي (Text)، العنوان الفرعي (Text)، رابط الزر (URL)، نص الزر (Text)، صورة الخلفية/الشخصية (File/Image).
    2.  **قسم الإحصائيات (Stats):**
        *   **المدخلات (Inputs):** إمكانية إضافة إحصائية (العنوان + الرقم/العداد).
    3.  **قسم الكتب (Books):** (مربوط بإدارة المنتجات/الكتب).
    4.  **إعدادات عامة (Global Settings):**
        *   **المدخلات (Inputs):** روابط السوشيال ميديا (Links)، اللوجو (Image)، نصوص الفوتر (Text).

### ب. إدارة الدورات (Courses Management)
*   **العمليات:** عرض (List with Pagination)، إضافة (Create)، تعديل (Edit)، حذف (Soft Delete).
*   **حقول الإدخال (Inputs) - (إضافة/تعديل):**
    *   عنوان الدورة (Text - Translatable).
    *   الرابط النظيف (Slug - Text).
    *   الوصف المختصر (Textarea).
    *   الوصف الكامل (Rich Text Editor / CKEditor).
    *   صورة الغلاف (File/Image).
    *   فيديو تعريفي (URL / File).
    *   السعر (Number).
    *   حالة الدورة (Select: مسودة، منشورة، مغلقة).

### ج. إدارة المقالات (Articles Management)
*   **العمليات:** عرض (List with Pagination)، إضافة (Create)، تعديل (Edit)، حذف (Soft Delete).
*   **حقول الإدخال (Inputs) - (إضافة/تعديل):**
    *   عنوان المقال (Text - Translatable).
    *   الرابط النظيف (Slug - Text).
    *   محتوى المقال (Rich Text Editor).
    *   صورة المقال (File/Image).
    *   تاريخ النشر (Date/Time).
    *   حالة المقال (Select: منشور، مسودة).

### د. إدارة المشتركين/المستخدمين (Users Management)
*   **العمليات:** عرض (List with Pagination)، حظر (Block/Unblock)، تعديل تفاصيل.
*   **حقول الإدخال (Inputs):**
    *   الاسم (Text).
    *   البريد الإلكتروني (Email).
    *   رقم الهاتف (Text).
    *   كلمة المرور (Password - اختياري عند التعديل).

---

## 3. التقنيات والأنماط المعمارية المستخدمة
*   **البنية:** تعتمد على Controller-Service-Repository (CSR).
*   **الواجهات:** استخدام Vuexy Template للوحة التحكم، وعمليات الأجاكس (AJAX Modal CRUD) لتجربة مستخدم سريعة (خاصة في التعديلات السريعة مثل الأقسام).
*   **الترجمة:** الاعتماد على حزمة `Mcamara/LaravelLocalization` و `Spatie/Translatable` لإدارة الحقول متعددة اللغات.
*   **إدارة الصور:** استخدام `HasImage` trait لمعالجة وحفظ الصور ديناميكياً.
